## 深夜流水线

```mermaid
flowchart LR
    A([凌晨的一个念头]) --> B[写几行草稿]
    B --> C{还清醒吗}
    C -- 清醒 --> D[继续写]
    C -- 不清醒 --> E[去睡]
    D --> F[天亮了]
    E --> F
    F --> A
```

## 这块主页

| 项目 | 说明 |
| --- | --- |
| 图形 | 五张手写 SVG，动画全部写在文件里，可以直接打开改 |
| 第三方服务 | 只有访问计数徽章一个，没有图表、动画或追踪服务 |
| 主题 | 面板自带深色底，浅色与深色主题下观感一致，无需双版本 |
| 交互 | SVG 作为图片渲染，无法响应 hover 或点击，所有效果都是自动播放 |
| 字体 | 只用系统字体栈，不加载外部字体 |
| 内容克制 | 不列技能清单，不放联系方式 |

> 夜里写的东西，白天再判断好不好看。
